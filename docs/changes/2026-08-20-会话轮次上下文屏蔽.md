# 会话轮次上下文屏蔽

## 变更

- 已完成 Agent 轮次的 footer 最右侧新增无彩色 `eye-off` 操作。
- 屏蔽范围覆盖本轮 user、assistant、thinking、tool call 和 tool result；历史消息仍完整可见，屏蔽轮次以低对比度显示。
- 屏蔽状态使用 Pi JSONL custom entry 持久化，支持刷新、重开会话、多轮屏蔽和幂等切换。
- provider 请求与后续 compaction 摘要输入都会排除屏蔽轮次；snapshot 和消息接口保留完整历史。
- 含工具调用的轮次在首次屏蔽前提示：上下文屏蔽不会撤销文件、命令或外部副作用。
- 修正多段 Agent 回复的轮次锚点：WebUI 与服务端统一使用本轮首条 assistant entry，避免最新回复被误显示为不可操作。

## 边界

- 已进入 compaction 的轮次暂不允许首次屏蔽或恢复。Pi SDK 当前没有原子替换任意历史摘要的公开操作，界面会明确禁用，不模拟成功。
- 屏蔽只移除目标轮次的原始消息；其他未屏蔽轮次中对相同信息的复述仍会进入模型上下文。
- 屏蔽或恢复会使变化点之后的 provider prompt cache 失效。

## 验证

- 浏览器验收通过：最新回复可正确识别并切换，按钮位置、状态和整轮显示符合预期。
- TypeScript 类型检查、88 项服务端测试、adapter JavaScript 语法、构建产物一致性和 `git diff --check` 通过。
