# 会话草稿工作台

## 变更

- 在输入框 `+` 菜单增加会话级草稿开关，激活控件复用 Swarm 的交互密度。
- Agent 通过 `session_draft` 创建、列出、读取和更新草稿；正文保存在 `PI_CODE_HOME`，不进入项目目录。
- 草稿使用不可变 revision、SHA-256 digest、乐观锁、原子索引和容量上限。
- 工具当前轮保留正文，后续 provider 请求与 compaction 输入只保留有界 metadata。
- 草稿卡片支持查看、引用、复制和保存 Markdown；查看弹窗可切换 revision。
- `request_publish` 固定 revision 并强制进入原生审批，目标路径限制在会话工作区，审批展示路径和 diff。
- 完整 fork 复制草稿快照；按消息分叉只复制分叉点前可见草稿；side chat 不继承。
- 删除会话时将草稿移入回收站，服务启动时清理超过 30 天的记录。

## 边界

- 草稿默认关闭；关闭时不注入能力提示，也不向 Provider 发送草稿工具 schema。
- 会话隔离不构成操作系统安全沙箱。同一系统用户下的无限制 Bash 仍可主动读取 `PI_CODE_HOME`。
- 发布只通过 Agent 工具进入审批链路，不提供绕过审批的 REST 写入接口。
- 暂不提供跨会话搜索、通用编辑器、Plan 自动联动或数据库存储。

## 验证

- 浏览器验收通过：草稿开关、Agent 创建、卡片、查看、引用和附件式 chip 均符合预期。
- TypeScript 类型检查、95 项服务端测试、adapter JavaScript 语法、冻结版产物同步和 `git diff --check` 通过。
- 自动测试覆盖 revision、固定版本发布、工作区路径限制、草稿复制、回收站和发布审批。
