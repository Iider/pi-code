# 2026-08-19 修复默认权限保存

## 需求

Agent 设置中的“风险确认”和“无需确认”无法选中。

## 方案与关键决策

- 采用方案：为 Pi Code 增加独立的轻量设置文件，保存默认权限模式；配置接口读写该字段。
- 原因：Pi SDK 的全局设置没有默认权限字段，不能写入其设置文件；独立文件避免混入模型配置或依赖浏览器本地存储。
- 否决方案：只更新前端状态，原因：刷新后会丢失；把字段塞进 `models.json`，原因：模型配置与界面偏好职责不同。

## 改动内容

- `server/src/models/pi-code-settings-store.ts`：新增 `pi-code-settings.json` 读写和权限模式校验。
- `server/src/models/configuration-service.ts`：配置接口返回并保存 `default_permission_mode`。
- `server/test/configuration-service.test.ts`：覆盖默认值、保存和重新加载。

## 业务流程变化

1. 设置页提交默认权限。
2. 服务端校验 `manual`、`auto` 或 `yolo`，并写入 `~/.pi/agent/pi-code-settings.json`。
3. 页面使用接口返回值显示当前选项，刷新后保持一致。

## 验证方式

- 服务端：12 个测试文件、81 项测试通过；TypeScript 类型检查通过。
- 页面验收：风险确认和无需确认均可选中；无需确认刷新页面后仍保持；测试后的默认值已恢复为逐项确认。
